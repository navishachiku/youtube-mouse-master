# Slippy Mouse

![Slippy Mouse](./images/banner.png)

เครื่องมือเสริมพลังเมาส์สำหรับเครื่องเล่นวิดีโอออนไลน์: แบ่งเครื่องเล่นออกเป็นสามโซน แล้วหมุน**ล้อเลื่อน**ในโซนเพื่อปรับระดับเสียง ความเร็วการเล่น การเลื่อนตำแหน่ง และอื่น ๆ — ลื่นไหลสุด ๆ ไม่ต้องจำปุ่มลัด ไม่ต้องมองหาปุ่ม แค่หมุนเบา ๆ ก็ถึงที่หมาย พร้อมแผงตั้งค่าให้ปรับแต่งทุกการทำงานของล้อเลื่อนและการคลิกได้ตามใจ

## ✨ จุดเด่น

* **รองรับหลายเว็บไซต์**: ใช้ได้ทั้ง **YouTube**, **Bilibili** (`www.bilibili.com`) และ **Bahamut Ani.Gamer** (`ani.gamer.com.tw`) โดยโซนและการทำงานเหมือนกันทุกเว็บ

* **ควบคุมด่วน**: กำหนดโซนการทำงานบนเครื่องเล่นให้ตอบสนองต่อการคลิกและการหมุนล้อ เพื่อปรับเสียง ความเร็ว ตำแหน่ง ฯลฯ ได้อย่างรวดเร็ว

* **โซนการทำงานปรับแต่งได้**: รองรับการตั้งค่าโซนอย่างละเอียด ปรับขนาดและตำแหน่งได้อิสระ (ค่าเริ่มต้นมีโซนซ้าย กลาง ขวา)

* **ไม่มีเลเยอร์บดบัง**: เลิกใช้เลเยอร์โปร่งใสแบบดั้งเดิม หันมาใช้การคำนวณพิกัดประสิทธิภาพสูง ไม่รบกวนการคลิก UI ดั้งเดิมอย่างแถบความคืบหน้าและปุ่มต่าง ๆ

* **ล้อเลื่อนแบบปรับตัว**: หนึ่งคลิกของล้อหรือหนึ่งการปัดเท่ากับหนึ่งการทำงานพอดีบนทุกอุปกรณ์ — ล้อเมาส์ ทัชแพด และซอฟต์แวร์เลื่อนแบบลื่น (Mos, SmoothScroll, Logitech Options+) — โดยไม่ต้องปรับจูน แรงเฉื่อยส่วนเกินถูกตัดทิ้ง ส่วนการปัดยาวโดยตั้งใจยังตอบสนองตามสัดส่วน

* **แผงตั้งค่าแบบกราฟิก**: ทุกพารามิเตอร์และการจับคู่โซน-การทำงานปรับได้ในแผงบนหน้าเว็บ — เปลี่ยนแล้วมีผลทันทีและบันทึกในเบราว์เซอร์ อัปเดตสคริปต์ไม่ทำให้การปรับแต่งหาย

## 🎛️ แผงตั้งค่า

ไม่ต้องแก้โค้ด — คลิกไอคอนเมาส์บนแถบควบคุมของเครื่องเล่นเพื่อเปิดแผงตั้งค่า:

![ทางเข้าแผงตั้งค่า](./images/settings-entry.png)

![Settings Panel](./images/settings-general.png)

* **สี่แท็บ**: ทั่วไป (ล้อเลื่อนแบบปรับตัว ปุ่มลัด ธีม OSD), การทำงานของโซน, ล้อเลื่อน (ปรับจูนอัตโนมัติและการกรองด้วยตนเอง) และขั้นสูง (ดีบัก ข้อมูลการตั้งค่า)
* **จับคู่การทำงานของโซน**: เลือกโซนสี แล้วกำหนดการทำงานพร้อมค่าให้แต่ละทริกเกอร์ (คลิกซ้าย / ขวา / กลาง, ล้อขึ้น / ลง):

![Zone Actions](./images/settings-zones.png)

* **มีผลทันทีและบันทึกถาวร**: การแก้ไขมีผลทันที; กด «บันทึก» เพื่อเขียนลงที่เก็บข้อมูลของเบราว์เซอร์ — **อัปเดตสคริปต์ไม่ทำให้การตั้งค่าหาย**; «ยกเลิก» หรือ Esc เพื่อย้อนกลับ
* **ปุ่มลัด**: แสดงโซนค่าเริ่มต้นคือ `Alt+Shift+Z`; ปุ่มลัดแผงตั้งค่ายังไม่กำหนดโดยค่าเริ่มต้น ทั้งคู่กำหนดใหม่ได้ในแผง รองรับปุ่มร่วม (Esc ยกเลิกการจับ, Backspace ล้างค่า)
* **ส่งออก / นำเข้า / รีเซ็ต**: สำรองการตั้งค่าเป็นไฟล์ JSON ย้ายไปเบราว์เซอร์อื่น หรือคืนค่าโรงงานได้ในคลิกเดียว
* **ภาษาอินเทอร์เฟซ**: เปลี่ยนตามภาษาเบราว์เซอร์ ถ้าไม่มีจะใช้ภาษาอังกฤษ; เลือกเองได้ในแผงตั้งค่า
* **ธีม**: สว่าง / มืด / อัตโนมัติ (ตามการตั้งค่าระบบ)

## ⚙️ พารามิเตอร์ที่ปรับแต่งได้

ทุกพารามิเตอร์ปรับได้ในแผงตั้งค่า (แนะนำ) หรือจะแก้บล็อก `SETTINGS` และ `CONFIG` ที่ส่วนหัวของสคริปต์โดยตรงก็ได้ แต่โปรดทราบว่าการแก้สคริปต์โดยตรงจะถูกเขียนทับเมื่อสคริปต์อัปเดต ส่วนการตั้งค่าในแผงจะคงอยู่

<details>
<summary><b>ขั้นสูง: ตารางพารามิเตอร์ฉบับเต็ม</b> (คลิกเพื่อขยาย)</summary>

### การตั้งค่าส่วนกลาง

| พารามิเตอร์ | คำอธิบาย | ค่าเริ่มต้น |
| :--- | :--- | :--- |
| `DEBUG` | แสดงข้อความดีบักในคอนโซลหรือไม่ | `false` |
| `ZONE_TOGGLE_KEY` | ปุ่มลัดสลับการแสดงโซน (รองรับปุ่มร่วม) | `Alt+Shift+Z` |
| `SETTINGS_TOGGLE_KEY` | ปุ่มลัดเปิดแผงตั้งค่า (ทางเข้าหลักคือปุ่มบนแถบควบคุม) | ยังไม่กำหนด |
| `OSD_DURATION` | เวลาที่ข้อความ OSD ค้างบนจอ (มิลลิวินาที) | `800` |
| `OSD_FADE_OUT` | ระยะเวลาแอนิเมชันจางหายของ OSD (มิลลิวินาที) | `150` |
| `OSD_FONT_SIZE` | ขนาดตัวอักษรข้อความ OSD (รองรับ px, em, rem ฯลฯ) | `28px` |
| `ADAPTIVE_WHEEL` | การกรองแบบปรับตัว: หนึ่งคลิก/หนึ่งปัด = หนึ่งการทำงานบนทุกอุปกรณ์ ตั้งเป็น `false` เพื่อใช้การกรองด้วยตนเองด้านล่าง | `true` |
| `WHEEL_STEP` | โหมดปรับตัว: ระยะเลื่อนสะสม (px) ต่อการทำงาน; ลดลงเพื่อความละเอียดขึ้น | `100` |
| `GESTURE_GAP` | ปรับตัว: ช่วงเงียบ (มิลลิวินาที) ที่ทำให้อินพุตนับเป็นท่าทางใหม่ | `150` |
| `MIN_ACTION_INTERVAL` | ปรับตัว: มิลลิวินาทีขั้นต่ำระหว่างสองการทำงาน; จำกัดความถี่ | `80` |
| `IMPULSE_MIN` | ปรับตัว: ระยะอิมพัลส์ขั้นต่ำ (px) ที่นับเป็นหนึ่งการทำงาน; กรองการเฉี่ยวโดน | `20` |
| `REACCEL_FACTOR` | ปรับตัว: อัตราการกระโดดของแอมพลิจูดที่บ่งชี้คลิกใหม่ในหางที่กำลังจาง | `1.5` |
| `DISCRETE_SETTLE` | ปรับตัว: หน่วงเวลายืนยัน (มิลลิวินาที) สำหรับคลิกล้อเดี่ยว | `60` |
| `USE_WHEEL_COUNT_FIXED` | โหมดกำหนดเองเท่านั้น: เปิดการกรองแบบนับครั้งคงที่ | `false` |
| `WHEEL_DELAY` | โหมดกำหนดเองเท่านั้น: หน่วงเวลาดีบาวน์ของเหตุการณ์ล้อ (มิลลิวินาที) | `1` |
| `WHEEL_COUNT_THRESHOLD` | เกณฑ์การนับ: สะสมเหตุการณ์ล้อกี่ครั้งจึงทำงานหนึ่งครั้ง | `14` |

### การกำหนดโซนเอง

คุณสามารถปรับแต่งโซนการทำงานได้ตามต้องการ ทั้งขนาดและตำแหน่ง

ค่าเริ่มต้นมีโซนซ้าย กลาง ขวา:

| โซน | คลิกซ้าย | คลิกขวา | การทำงานของล้อ |
| ----- | ----- | ----- | ----- |
| **ซ้าย (เสียง)** | เสียงสูงสุด (100%) | ปิดเสียงด่วน (0%) | เสียงทีละ +/- 5% |
| **กลาง (ตำแหน่ง)** | ปล่อยผ่าน (เล่น/หยุดดั้งเดิม) | ปล่อยผ่าน (เมนูดั้งเดิม) | เลื่อน +/- 5 วิ |
| **ขวา (ความเร็ว)** | 2.0x ด่วน | กลับ 1.0x | ความเร็วทีละ +/- 0.25x |

### รายการการทำงานที่รองรับ

ใน `mouse_action` ประเภท `action` ที่ใช้ได้มีดังนี้:

| ชื่อการทำงาน (action) | คำอธิบาย | ตัวอย่างพารามิเตอร์ (value) |
| :--- | :--- | :--- |
| `volume_up` | เพิ่มเสียง | `5` (หมายถึง +5%) |
| `volume_down` | ลดเสียง | `5` (หมายถึง -5%) |
| `volume_set` | ตั้งระดับเสียงคงที่ | `0` (ปิดเสียง) หรือ `100` (สูงสุด) |
| `volume_mute` | สลับปิด/เปิดเสียง | ไม่ต้องมีพารามิเตอร์ |
| `seek` | กระโดดตำแหน่ง | `5` (ไปหน้า) หรือ `-5` (ถอยหลัง) |
| `toggle_play_pause` | สลับเล่น / หยุดชั่วคราว | ไม่ต้องมีพารามิเตอร์ |
| `speed_up` | เพิ่มความเร็วการเล่น | `0.25` |
| `speed_down` | ลดความเร็วการเล่น | `0.25` |
| `speed_set` | ตั้งความเร็วคงที่ | `1.0`, `2.0` ฯลฯ |
| `none` | ไม่ทำอะไร | ส่งเหตุการณ์ให้เว็บไซต์จัดการตามปกติ |

</details>

## 📦 การติดตั้ง

**วิธีที่ 1: ติดตั้ง Userscript คลิกเดียว (แนะนำ ใช้ได้กับเบราว์เซอร์หลักทุกตัว)**

1. ติดตั้งส่วนขยายเบราว์เซอร์ [Tampermonkey](https://www.tampermonkey.net/)
2. ไปที่ **[หน้าสคริปต์บน GreasyFork](https://greasyfork.org/scripts/566499)**
3. คลิกปุ่ม **«ติดตั้งสคริปต์นี้»**

**วิธีที่ 2: ส่วนขยายเบราว์เซอร์**

กำลังเตรียมเผยแพร่บน Microsoft Edge Add-ons หรือดาวน์โหลดโฟลเดอร์ `extension/` จาก repo นี้ แล้วโหลดด้วยตนเองจากหน้าส่วนขยายของเบราว์เซอร์โดยเปิดโหมดนักพัฒนา

**วิธีที่ 3: ติดตั้ง Userscript ด้วยตนเอง**

1. สร้าง «สคริปต์ใหม่» ใน Tampermonkey
2. คัดลอกเนื้อหาทั้งหมดของ `SlippyMouse.user.js` แล้ววาง
3. บันทึกแล้วใช้งานได้เลย!
