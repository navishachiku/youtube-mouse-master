# Slippy Mouse

![Slippy Mouse](./images/banner.png)

온라인 동영상 플레이어를 위한 마우스 강화 도구입니다. 플레이어를 3개의 감지 존으로 나누고, 존 안에서 마우스 **휠**만 굴리면 볼륨·재생 속도·탐색 등을 조작할 수 있습니다. 부드럽고 쾌적하며, 단축키를 외울 필요도 버튼을 찾을 필요도 없습니다. 가볍게 한 번 굴리면 끝. 휠/클릭 동작은 설정 패널에서 자유롭게 커스터마이즈할 수 있습니다.

## ✨ 주요 기능

* **멀티 사이트 지원**: **YouTube**, **Bilibili**(`www.bilibili.com`), **Bahamut Ani.Gamer**(`ani.gamer.com.tw`)를 모두 지원하며, 모든 사이트에서 동일한 존과 액션을 사용할 수 있습니다.

* **빠른 제어**: 클릭 및 휠 스크롤과 같은 마우스 동작에 대응하는 커스텀 액션 존을 플레이어에 설정하여 볼륨, 속도, 재생 위치 등을 빠르게 조정할 수 있습니다.

* **커스텀 액션 존**: 감지 영역 설정을 자유롭게 조정할 수 있습니다. 영역 크기와 위치를 자유롭게 변경할 수 있습니다 (기본값으로 왼쪽, 중앙, 오른쪽 3개 영역 설정 제공).

* **제로 오버레이 상호작용 (Zero-Overlay)**: 기존의 투명 레이어 덮어쓰기 방식을 버리고 고성능 좌표 계산 방식을 채택하여 프로그레스 바나 버튼 등 기본 UI 클릭을 방해하지 않습니다.

* **적응형 휠**: 어떤 장치에서든 "휠 한 칸 또는 스와이프 한 번 = 정확히 한 번의 동작". 마우스 휠, 트랙패드, 부드러운 스크롤 소프트웨어(Mos, SmoothScroll, Logitech Options+)에 설정 없이 자동 적응합니다. 관성 꼬리는 억제되고 의도적인 긴 스와이프는 비례 반응을 유지합니다.

* **그래픽 설정 패널**: 모든 매개변수와 존 동작 매핑을 페이지 내 패널에서 조정할 수 있습니다. 설정은 즉시 적용되고 브라우저에 저장되어 스크립트 업데이트 후에도 유지됩니다.

## 🎛️ 설정 패널

코드 수정이 필요 없습니다. 플레이어 컨트롤 바의 마우스 아이콘을 클릭하면 설정 패널이 열립니다:

![설정 패널 진입점](./images/settings-entry.png)

![Settings Panel](./images/settings-general.png)

* **4개의 탭**: 일반(적응형 휠, 단축키, 모양, OSD), 존 동작, 휠(적응형 조정과 수동 필터링), 고급(디버그, 설정 데이터).
* **존 동작 매핑**: 3색 존을 선택하고 각 존의 좌／우／중간 클릭, 휠 위／아래에 원하는 동작과 매개변수를 지정할 수 있습니다:

![Zone Actions](./images/settings-zones.png)

* **즉시 적용과 지속성**: 변경 사항은 즉시 적용됩니다. "저장"은 브라우저 저장소에 기록되어 **스크립트 업데이트 후에도 설정이 유지됩니다**. "취소" 또는 Esc로 되돌릴 수 있습니다.
* **단축키**: 존 표시 기본값은 `Alt+Shift+Z`, 패널 단축키는 기본 미설정. 둘 다 패널에서 재지정 가능합니다(조합키 지원, 캡처 중 Esc 취소, Backspace 지우기).
* **내보내기／가져오기／초기화**: 설정을 JSON 파일로 백업해 다른 브라우저로 옮기거나 클릭 한 번으로 기본값을 복원할 수 있습니다.
* **인터페이스 언어**: 브라우저 언어에 따라 자동 전환. 해당 없으면 영어. 패널에서 직접 지정할 수도 있습니다.
* **테마**: 라이트／다크／자동(시스템 설정 따름).

## ⚙️ 설정 가능한 파라미터

모든 매개변수는 설정 패널에서 조정할 수 있습니다(권장). 스크립트 상단의 `SETTINGS` 및 `CONFIG` 블록을 직접 편집할 수도 있지만, 직접 수정한 내용은 스크립트 업데이트 시 덮어써집니다. 패널 설정은 유지됩니다.

### 글로벌 설정 (Global Settings)

| 파라미터 | 설명 | 기본값 |
| :--- | :--- | :--- |
| `DEBUG` | 콘솔에 디버그 메시지 출력 여부 | `false` |
| `ZONE_TOGGLE_KEY` | 영역 시각화 활성화/비활성화 단축키(조합키 지원) | `Alt+Shift+Z` |
| `SETTINGS_TOGGLE_KEY` | 설정 패널을 여는 단축키(주 진입점은 컨트롤 바 버튼) | 미설정 |
| `OSD_DURATION` | OSD 알림이 화면에 머무는 시간 (ms) | `800` |
| `OSD_FADE_OUT` | OSD 서서히 사라지는 애니메이션 시간 (ms) | `150` |
| `OSD_FONT_SIZE` | OSD 텍스트 글꼴 크기 (px, em, rem 등 지원) | `28px` |
| `ADAPTIVE_WHEEL` | 적응형 휠: 어떤 장치에서든 한 칸/한 스와이프 = 한 동작. `false`로 설정하면 아래의 수동 필터링 설정 사용 | `true` |
| `WHEEL_STEP` | 적응형 모드: 동작 한 번에 필요한 누적 스크롤 양 (px). 낮출수록 민감해짐 | `100` |
| `GESTURE_GAP` | 적응형: 이 시간(ms) 이상 조용하면 새 제스처로 간주 | `150` |
| `MIN_ACTION_INTERVAL` | 적응형: 동작 간 최소 간격(ms), 버스트 피해 상한 | `80` |
| `IMPULSE_MIN` | 적응형: 한 동작으로 정산되는 최소 스크롤 양(px), 오터치 필터링 | `20` |
| `REACCEL_FACTOR` | 적응형: 감쇠 꼬리에서 "새 노치"로 판정하는 크기 급증 배율 | `1.5` |
| `DISCRETE_SETTLE` | 적응형: 단일 이벤트 노치(순정 휠 한 칸)의 정산 지연(ms) | `60` |
| `USE_WHEEL_COUNT_FIXED` | 수동 모드 전용: 고정 휠 카운트 필터링 사용 여부 | `false` |
| `WHEEL_DELAY` | 수동 모드 전용: 휠 이벤트 디바운스 지연 시간 (ms) | `1` |
| `WHEEL_COUNT_THRESHOLD` | 휠 카운트 트리거 임계값: 동작 실행 전 누적할 휠 이벤트 수 | `14` |

### 커스텀 영역 설정 (Custom Zone Configuration)

개인적인 필요에 따라 액션 영역의 크기와 위치를 완전히 커스텀할 수 있습니다.

기본적으로 왼쪽, 중앙, 오른쪽 3개 영역 설정을 제공합니다:

| 영역 | 왼쪽 클릭 | 오른쪽 클릭 | 휠 동작 |
| ----- | ----- | ----- | ----- |
| **왼쪽 (볼륨)** | 최대 볼륨 (100%) | 빠른 음소거 (0%) | 볼륨 조정 +/- 5% |
| **중앙 (재생 위치)** | 기본 동작 (재생/일시정지) | 기본 동작 (콘텍스트 메뉴) | 재생 위치 이동 +/- 5초 |
| **오른쪽 (재생 속도)** | 빠른 2.0x | 초기화 1.0x | 재생 속도 조정 +/- 0.25x |

### 지원 액션 목록 (Supported Actions List)

`mouse_action` 내에서 사용할 수 있는 `action` 종류는 다음과 같습니다:

| 액션 이름 (action) | 설명 | 파라미터 예시 (value) |
| :--- | :--- | :--- |
| `volume_up` | 볼륨 증가 | `5` (+5% 의미) |
| `volume_down` | 볼륨 감소 | `5` (-5% 의미) |
| `volume_set` | 고정 볼륨 설정 | `0` (음소거) 또는 `100` (최대) |
| `volume_mute` | 음소거 전환 / 해제 | 파라미터 필요 없음 |
| `seek` | 재생 위치 이동 | `5` (앞으로) 또는 `-5` (뒤로) |
| `toggle_play_pause` | 재생 / 일시정지 상태 전환 | 파라미터 필요 없음 |
| `speed_up` | 재생 속도 증가 | `0.25` |
| `speed_down` | 재생 속도 감소 | `0.25` |
| `speed_set` | 고정 재생 속도 설정 | `1.0`, `2.0` 등 |
| `none` | 아무 작업도 하지 않음 | 이벤트를 사이트 기본 처리 방식으로 넘깁니다 |

## 📦 설치 방법

**방법 1: Userscript 원클릭 설치(권장, 모든 주요 브라우저 지원)**

1. 브라우저 확장 프로그램 [Tampermonkey](https://www.tampermonkey.net/)를 설치합니다.
2. **[GreasyFork 스크립트 페이지](https://greasyfork.org/scripts/566499)**로 이동합니다.
3. **「이 스크립트 설치」** 버튼을 클릭합니다.

**방법 2: 브라우저 확장 버전**

**[Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/mkheoimiiokaclpjjlfokkkkdlfbhhib)**에서 설치할 수 있습니다. 이 repo의 `extension/` 디렉터리를 내려받아 브라우저 확장 페이지에서 개발자 모드를 켜고 수동으로 로드할 수도 있습니다.

**방법 3: Userscript 수동 설치**

1. Tampermonkey에서 「새 스크립트」를 만듭니다.
2. `SlippyMouse.user.js`의 내용을 복사하여 붙여넣습니다.
3. 저장하면 바로 사용할 수 있습니다!
