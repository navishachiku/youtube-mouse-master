# Slippy Mouse

![Slippy Mouse](./images/banner.png)

オンライン動画プレイヤーのためのマウス拡張ツール。プレイヤーを3つのゾーンに分け、ゾーン内でマウス**ホイール**を回すだけで音量・再生速度・シークなどを操作できます。なめらかで快適、ショートカットを覚える必要も、ボタンを探す必要もありません。ひと転がしで思いどおり。ホイールやクリックの動作は設定パネルで自由にカスタマイズできます。

## ✨ 主な特徴

* **マルチサイト対応**: **YouTube**、**Bilibili**（`www.bilibili.com`）、**Bahamut Ani.Gamer**（`ani.gamer.com.tw`）で動作し、どのサイトでも同一のゾーンとアクションが利用できます。

* **クイックコントロール**: プレイヤー上にカスタムアクションゾーンを設定し、クリックやホイール操作で音量、速度、シークなどを素早く調整できます。

* **カスタムアクションゾーン**: センサーゾーンの設定を高度にカスタマイズ可能。サイズや位置を自由に変更できます（デフォルトでは左・中・右の3ゾーン設定を用意）。

* **ゼロオーバーレイ操作**: 従来の透明レイヤーでのカバーを廃止し、高性能な座標計算を採用。プログレスバーやボタンなどのネイティブ UI のクリックを一切妨げません。

* **アダプティブホイール**: どのデバイスでも「ノッチ1回・スワイプ1回 = ちょうど1アクション」。マウスホイール、トラックパッド、スムーススクロールソフト（Mos、SmoothScroll、Logitech Options+）に設定不要で自動適応。慣性の尾は抑制され、意図的なロングスワイプは比例レスポンスを維持します。

* **グラフィカル設定パネル**: すべてのパラメータとゾーン操作の割り当てをページ内パネルで調整できます。設定は即時反映され、ブラウザに保存されるため、スクリプト更新後も失われません。

## 🎛️ 設定パネル

コードの編集は不要です。プレイヤーのコントロールバーにあるマウスアイコンをクリックすると設定パネルが開きます：

![設定パネルの入り口](./images/settings-entry.png)

![Settings Panel](./images/settings-general.png)

* **4つのタブ**: 一般（アダプティブホイール、ホットキー、外観、OSD）、ゾーン操作、ホイール（アダプティブ調整と手動フィルタリング）、詳細（デバッグ、設定データ）。
* **ゾーン操作の割り当て**: 3色のゾーンを選び、各ゾーンの左／右／中クリック、ホイール上下に任意のアクションとパラメータを割り当てられます：

![Zone Actions](./images/settings-zones.png)

* **即時反映と永続化**: 変更は即座に適用。「保存」でブラウザに保存され、**スクリプト更新後も設定は失われません**。「キャンセル」または Esc で元に戻せます。
* **ホットキー**: ゾーン表示のデフォルトは `Alt+Shift+Z`。パネルのホットキーはデフォルト未設定。どちらもパネル内で再割り当て可能（修飾キーの組み合わせ対応、キャプチャ中は Esc でキャンセル、Backspace でクリア）。
* **エクスポート／インポート／リセット**: 設定を JSON ファイルとしてバックアップ・移行、またはワンクリックでデフォルトに戻せます。
* **インターフェース言語**: ブラウザの言語設定に従って自動切替。該当なしの場合は英語。パネルから手動で指定することも可能。
* **外観テーマ**: ライト／ダーク／自動（システム設定に追従）。

## ⚙️ カスタマイズ可能なパラメータ

すべてのパラメータは設定パネルで調整できます（推奨）。スクリプト冒頭の `SETTINGS` と `CONFIG` ブロックを直接編集することもできますが、直接編集した内容はスクリプト更新時に上書きされます。パネルの設定は保持されます。

### グローバル設定 (Global Settings)

| パラメータ | 説明 | デフォルト値 |
| :--- | :--- | :--- |
| `DEBUG` | コンソールにデバッグメッセージを出力するか | `false` |
| `ZONE_TOGGLE_KEY` | ゾーンの可視化を切り替えるホットキー（修飾キーの組み合わせに対応） | `Alt+Shift+Z` |
| `SETTINGS_TOGGLE_KEY` | 設定パネルを開くホットキー（メインの入口はコントロールバーのボタン） | 未設定 |
| `OSD_DURATION` | OSD 表示が画面に留まる時間 (ms) | `800` |
| `OSD_FADE_OUT` | OSD のフェードアウトアニメーション時間 (ms) | `150` |
| `OSD_FONT_SIZE` | OSD テキストのフォントサイズ (px, em, rem などに対応) | `28px` |
| `ADAPTIVE_WHEEL` | アダプティブホイール：どのデバイスでもノッチ/スワイプ1回 = 1アクション。`false` で下記の手動フィルタリング設定を使用 | `true` |
| `WHEEL_STEP` | アダプティブモード：1アクションに必要な累積スクロール量 (px)。下げると敏感になる | `100` |
| `GESTURE_GAP` | アダプティブ：この静止時間 (ms) を超えると新しいジェスチャーと見なす | `150` |
| `MIN_ACTION_INTERVAL` | アダプティブ：アクション間の最小間隔 (ms)。バーストの影響を制限 | `80` |
| `IMPULSE_MIN` | アダプティブ：1アクションとして確定する最小スクロール量 (px)。誤タッチを除外 | `20` |
| `REACCEL_FACTOR` | アダプティブ：減衰中に「新しいノッチ」と判定する振幅の跳ね上がり倍率 | `1.5` |
| `DISCRETE_SETTLE` | アダプティブ：単一イベントのノッチ（生ホイール1目盛り）の確定遅延 (ms) | `60` |
| `USE_WHEEL_COUNT_FIXED` | 手動モードのみ：固定ホイールカウントフィルタリングを有効にするか | `false` |
| `WHEEL_DELAY` | 手動モードのみ：ホイールイベントのデバウンス遅延時間 (ms) | `1` |
| `WHEEL_COUNT_THRESHOLD` | ホイールカウントの実行しきい値：累積したイベント数でアクションを実行 | `14` |

### カスタムゾーン設定 (Custom Zone Configuration)

個人のニーズに合わせて、アクションゾーンのサイズや位置を完全にカスタマイズできます。

デフォルトでは以下の左・中・右の3ゾーンが設定されています：

| ゾーン | 左クリック | 右クリック | ホイール操作 |
| ----- | ----- | ----- | ----- |
| **左側 (音量)** | 最大音量 (100%) | クイックミュート (0%) | 音量ステップ +/- 5% |
| **中央 (シーク)** | パススルー (ネイティブの再生/一時停止) | パススルー (ネイティブのメニュー) | シーク +/- 5秒 |
| **右側 (再生速度)** | クイック 2.0x | リセット 1.0x | 速度ステップ +/- 0.25x |

### サポートされているアクション一覧 (Supported Actions List)

`mouse_action` 内で使用可能な `action` タイプは以下の通りです：

| アクション名 (action) | 説明 | パラメータ例 (value) |
| :--- | :--- | :--- |
| `volume_up` | 音量を上げる | `5` (+5% を意味します) |
| `volume_down` | 音量を下げる | `5` (-5% を意味します) |
| `volume_set` | 固定の音量を設定 | `0` (ミュート) または `100` (最大) |
| `volume_mute` | ミュート / ミュート解除の切り替え | パラメータ不要 |
| `seek` | シーク移動 | `5` (進む) または `-5` (戻る) |
| `toggle_play_pause` | 再生 / 一時停止の切り替え | パラメータ不要 |
| `speed_up` | 再生速度を上げる | `0.25` |
| `speed_down` | 再生速度を下げる | `0.25` |
| `speed_set` | 固定の再生速度を設定 | `1.0`, `2.0` など |
| `none` | 何もしない | サイトのネイティブ動作を優先します |

</details>

## 📦 インストール方法

**方法1：Userscript ワンクリックインストール（推奨、主要ブラウザ対応）**

1. ブラウザ拡張機能 [Tampermonkey](https://www.tampermonkey.net/) をインストールします。
2. **[GreasyFork スクリプトページ](https://greasyfork.org/scripts/566499)** にアクセスします。
3. **「このスクリプトをインストール」** ボタンをクリックします。

**方法2：ブラウザ拡張機能版**

**[Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/mkheoimiiokaclpjjlfokkkkdlfbhhib)** で公開中です。本リポジトリの `extension/` ディレクトリをダウンロードし、ブラウザの拡張機能ページでデベロッパーモードを有効にして手動で読み込むこともできます。

**方法3：Userscript 手動インストール**

1. Tampermonkey で「新規スクリプト」を作成します。
2. `SlippyMouse.user.js` の内容をコピーして貼り付けます。
3. 保存すれば完了です！
