# Slippy Mouse

![Slippy Mouse](./images/banner.png)

Инструмент расширения возможностей мыши для онлайн-видеоплееров: плеер делится на три зоны, и прокрутка **колеса** внутри зоны регулирует громкость, скорость воспроизведения, перемотку и многое другое — идеально плавно. Не нужно запоминать горячие клавиши и искать кнопки; достаточно одного лёгкого движения колеса. Панель настроек позволяет настроить каждое действие колеса и кликов.

## ✨ Ключевые возможности

* **Поддержка нескольких сайтов**: Работает на **YouTube**, **Bilibili** (`www.bilibili.com`) и **Bahamut Ani.Gamer** (`ani.gamer.com.tw`) с одинаковыми зонами и действиями на всех сайтах.

* **Быстрое управление**: Настройте собственные зоны действий на плеере, привязанные к действиям мыши — кликам и прокрутке колеса — для быстрой регулировки громкости, скорости, позиции и т.д.

* **Настраиваемые зоны действий**: Гибкая настройка сенсорных зон со свободным изменением размера и положения (по умолчанию: левая, средняя и правая зоны).

* **Взаимодействие без перекрытий**: Вместо традиционных прозрачных слоёв используются высокопроизводительные вычисления координат — без каких-либо помех для нативных элементов интерфейса вроде полосы прогресса и кнопок.

* **Адаптивное колесо**: Один щелчок колеса или свайп равен ровно одному действию на любом устройстве — колёса мыши, трекпады и программы плавной прокрутки (Mos, SmoothScroll, Logitech Options+) — без какой-либо настройки. Инерционные хвосты подавляются, а намеренные длинные свайпы остаются пропорциональными.

* **Графическая панель настроек**: Каждый параметр и каждая привязка зона-действие настраиваются в панели прямо на странице — изменения применяются мгновенно и сохраняются в браузере, обновления скрипта никогда не стирают ваши настройки.

## 🎛️ Панель настроек

Правка кода не нужна — нажмите на значок мыши в панели управления плеера, чтобы открыть настройки:

![Вход в панель настроек](./images/settings-entry.png)

![Settings Panel](./images/settings-general.png)

* **Четыре вкладки**: Общие (адаптивное колесо, горячие клавиши, оформление, OSD), Действия зон, Колесо (адаптивная настройка и ручная фильтрация) и Дополнительно (отладка, данные настроек).
* **Привязка действий к зонам**: Выберите цветную зону и назначьте любое действие с параметром каждому триггеру (левый / правый / средний клик, колесо вверх / вниз):

![Zone Actions](./images/settings-zones.png)

* **Мгновенное применение и сохранение**: Изменения действуют сразу; «Сохранить» записывает их в хранилище браузера — **обновления скрипта никогда не стирают настройки**; «Отмена» или Esc откатывает.
* **Горячие клавиши**: Показ зон по умолчанию — `Alt+Shift+Z`; клавиша панели по умолчанию не назначена. Обе переназначаются в панели с поддержкой комбинаций модификаторов (Esc отменяет захват, Backspace очищает).
* **Экспорт / Импорт / Сброс**: Сохраните настройки в JSON-файл, перенесите их в другой браузер или верните заводские значения одним кликом.
* **Язык интерфейса**: Следует языку браузера, по умолчанию английский; в панели доступен ручной выбор.
* **Оформление**: Светлая / тёмная / авто (следует системной настройке).

## ⚙️ Настраиваемые параметры

Каждый параметр можно изменить в панели настроек (рекомендуется). Можно также напрямую редактировать блоки `SETTINGS` и `CONFIG` в начале скрипта, но учтите: прямые правки скрипта затираются при его обновлении, а настройки панели сохраняются.

<details>
<summary><b>Дополнительно: полный справочник параметров</b> (нажмите, чтобы развернуть)</summary>

### Глобальные настройки

| Параметр | Описание | По умолчанию |
| :--- | :--- | :--- |
| `DEBUG` | Выводить отладочные сообщения в консоль | `false` |
| `ZONE_TOGGLE_KEY` | Горячая клавиша показа зон (поддерживаются комбинации модификаторов) | `Alt+Shift+Z` |
| `SETTINGS_TOGGLE_KEY` | Горячая клавиша открытия панели настроек (основной вход — кнопка в панели управления) | Не задано |
| `OSD_DURATION` | Время показа OSD-подсказок (мс) | `800` |
| `OSD_FADE_OUT` | Длительность анимации затухания OSD (мс) | `150` |
| `OSD_FONT_SIZE` | Размер текста OSD (px, em, rem и т.д.) | `28px` |
| `ADAPTIVE_WHEEL` | Адаптивная фильтрация: один щелчок/свайп = одно действие на любом устройстве. Установите `false` для ручной фильтрации ниже | `true` |
| `WHEEL_STEP` | Адаптивный режим: накопленная прокрутка (px) на действие; ниже — точнее | `100` |
| `GESTURE_GAP` | Адаптивный: тишина (мс), после которой ввод считается новым жестом | `150` |
| `MIN_ACTION_INTERVAL` | Адаптивный: минимум мс между двумя действиями; ограничивает всплески | `80` |
| `IMPULSE_MIN` | Адаптивный: минимальный ход импульса (px) для фиксации действия; отсеивает касания | `20` |
| `REACCEL_FACTOR` | Адаптивный: коэффициент скачка амплитуды, отмечающий новый щелчок в затухающем хвосте | `1.5` |
| `DISCRETE_SETTLE` | Адаптивный: задержка фиксации (мс) для одиночных щелчков колеса | `60` |
| `USE_WHEEL_COUNT_FIXED` | Только ручной режим: включить фильтрацию с фиксированным счётом | `false` |
| `WHEEL_DELAY` | Только ручной режим: задержка антидребезга событий колеса (мс) | `1` |
| `WHEEL_COUNT_THRESHOLD` | Порог счёта: сколько событий колеса накопить перед выполнением действия | `14` |

### Пользовательская конфигурация зон

Вы можете полностью настроить зоны действий под свои нужды, изменяя их размер и положение.

По умолчанию: левая, средняя и правая зоны:

| Зона | Левый клик | Правый клик | Действие колеса |
| ----- | ----- | ----- | ----- |
| **Левая (Громкость)** | Максимум (100%) | Быстрое отключение звука (0%) | Громкость +/- 5% |
| **Средняя (Прогресс)** | Пропуск (нативное воспроизведение/пауза) | Пропуск (нативное меню) | Перемотка +/- 5с |
| **Правая (Скорость)** | Быстро 2.0x | Возврат к 1.0x | Скорость +/- 0.25x |

### Список поддерживаемых действий

В `mouse_action` доступны следующие типы `action`:

| Имя действия (action) | Описание | Пример параметра (value) |
| :--- | :--- | :--- |
| `volume_up` | Увеличить громкость | `5` (означает +5%) |
| `volume_down` | Уменьшить громкость | `5` (означает -5%) |
| `volume_set` | Задать фиксированную громкость | `0` (без звука) или `100` (макс.) |
| `volume_mute` | Переключить звук вкл/выкл | Параметр не нужен |
| `seek` | Перемотать | `5` (вперёд) или `-5` (назад) |
| `toggle_play_pause` | Переключить воспроизведение / паузу | Параметр не нужен |
| `speed_up` | Увеличить скорость воспроизведения | `0.25` |
| `speed_down` | Уменьшить скорость воспроизведения | `0.25` |
| `speed_set` | Задать фиксированную скорость | `1.0`, `2.0` и т.д. |
| `none` | Ничего не делать | Передаёт событие нативной обработке сайта |

</details>

## 📦 Установка

**Способ 1: Установка userscript в один клик (рекомендуется, работает во всех основных браузерах)**

1. Установите расширение браузера [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте **[страницу скрипта на GreasyFork](https://greasyfork.org/scripts/566499)**.
3. Нажмите кнопку **«Установить этот скрипт»**.

**Способ 2: Расширение браузера**

Публикация в Microsoft Edge Add-ons готовится. Также можно скачать каталог `extension/` этого репозитория и загрузить его вручную на странице расширений браузера с включённым режимом разработчика.

**Способ 3: Ручная установка userscript**

1. Создайте «Новый скрипт» в Tampermonkey.
2. Скопируйте и вставьте содержимое `SlippyMouse.user.js`.
3. Сохраните и пользуйтесь!
